# 拾音

一个本地口琴曲谱播放器。打开曲谱，试听，再切回游戏播放。不需要账号、网络服务或大模型。

## 使用

打开 `app/DeltaPlayer.exe`。发布目录自带运行组件，不需要另装 .NET；请保留整个 app 文件夹，不要只移动 EXE。

1. 打开或拖入 MIDI / TXT 曲谱。
2. 试听适配后的旋律。多声部 MIDI 可以点“换个声部”。
3. 在游戏里装备口琴。点击界面的播放／继续按钮后，有 3 秒时间切回游戏；在游戏内按 F8 则立即播放／继续。

F8 播放／暂停，F9 停止。停止热键被其他程序占用时禁止游戏播放，试听仍可用。退出其他占用热键的播放器，再重新打开本程序即可。暂停会松开按键，继续时从下一个音开始；切出游戏会停止。

当前游戏窗口识别要求进程名称包含 `DeltaForce`。找不到时会提示，不会把浏览器或任意外部窗口当成目标。请先启动游戏。程序不自动提权，不自动抢焦点。

## 简谱示例

```text
BPM=100
1 1 5 5 6 6 5- | 4 4 3 3 2 2 1-
```

默认 BPM=120，1=C4。`0` 休止，`#1` 升半音，`1_` 半拍，`1__` 四分之一拍，`1.` 附点，`1-` 两拍；`【1】` 高八度，`(1)` 低八度。空格、换行、竖线只用于排版。只支持明确语法的 UTF-8 TXT，不解析任意歌词、Markdown 或图片。

`app/example.txt` 是可直接打开的示例。

## 自动处理与边界

MIDI 支持标准 SMF 0 / 1、PPQ 计时、全局速度变化，排除打击乐声道。推荐声部是规则排序，不保证识别出真正主旋律。和弦取最高起音，新音截断旧音；不会恢复被覆盖的伴奏尾音。

程序尝试整首升降八度、最多相对所选速度放慢 15%，不逐音折返。超出音域时，需明确选择播放可演奏部分；过密而无法可靠安排的旋律会提示，不会大量删音或无限顺延。

此版本的乐器映射采用 C4 中音、Z X C V B N M 与逗号、鼠标左／右八度、中键升半音预设。映射与时序尚未在用户当前游戏版本实测；Windows 接收输入不代表游戏必然识别或发声。试听使用本机 MIDI 合成器，设备不可用会明确提示。

## 本地数据

曲谱只读，不改写原文件。最近文件夹与速度设置保存在 `%LOCALAPPDATA%/DeltaPlayer/settings.json`。诊断在内存中最多保留 256 条，用户点击“复制诊断信息”时写入剪贴板；程序没有网络请求或遥测上传。

## 开发

源码在 `src`，测试在 `tests`。C# / WPF，.NET 10，DryWetMIDI 7.2.0 固定依赖。构建需 .NET 10 SDK，运行发布版本则无需 SDK。

```powershell
./build.ps1
# 也可指定隔离 SDK
./build.ps1 -DotnetPath 'C:/path/to/dotnet.exe'
```

构建脚本先运行模拟输入测试，通过后才发布。结果在 `artifacts/app`。不要在仍打开该目录中的程序时覆盖构建；使用独立输出目录或正常关闭程序。

详细实现与验证范围见 `开发与验证.md`。原始三仓库分析只作为设计参考，本程序没有合并其应用代码。
